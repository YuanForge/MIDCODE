# Sol 6.1 long-context threshold — v1.0.76

User-selected MIDCODE policy: every channel with canonical model `gpt-6.1-sol`
uses a 500,000-input-token short tier. Exactly 500,000 is short; 500,001 is long.
Input includes cached tokens. Output does not select the tier. Long requests
multiply all input/cache rates by 2 and output rates by 1.5, after existing
VIP/group and speed-tier pricing. Other models retain the 272,000 default.
This is the user's platform pricing policy, not official API pricing guidance.
No historical balances or logs are rewritten and base prices are unchanged.

The production source differs from the repository's historical backend baseline.
`deploy/sol61-context-20261104/apply.py` is the reviewed, count-checked patch
against the preserved production source used for v1.0.69. Rebuilding that
unmodified source reproduced the live server SHA256 exactly:
`c5b281f55681fbecce0b9835ecc99f83ddf7f5feb77793acd0259c23d193d710`.
The unmodified frontend index also matched production. Do not replace production
with this repository's older backend wholesale. Build hashes are in `build.json`.
Copy the accompanying regression test into `internal/billing` before testing.

Verified locally: focused billing/handler context, token-price, refund and retry
tests; explicit 272000/272001/353287/500000/500001 boundaries with zero and nearly
full cache hits, both sale and upstream cost; TypeScript/Vite build. No paid
upstream calls were needed for these tests.

Release commit is resolved by tag `v1.0.76`. Candidate image:
`fanapi-api:sol61-v1.0.76`; container `midcode-sol61-v1076-api-1`, port 8151.
Predecessor: `midcode-retry-v1069-api-1`, port 8149. The deployment script checks

`proxy-*.before`. These private snapshots must never be committed. `final.json`

## Dependency migration (operations tag v1.0.77)

The unified studio uses a fixed loopback backend at 8149. Preserve its running
image/video tasks by forwarding new loopback connections to 8151 with the
dedicated `fanapi-main-compat.service`; conntrack preserves established old
requests until completion. This replaces the old-container dependency without
restarting the studio or sharing its task database between two instances.
Install `backend-compat.sh` at `/usr/local/sbin/fanapi-main-compat` (0755), install
the supplied unit, daemon-reload and enable/start it. The rule affects only new
local TCP connections to 127.0.0.1:8149. Do not flush any firewall chain.

The API image remains v1.0.76 (commit 27ff4f1); v1.0.77 records this operational
dependency migration and cleanup guard, not a different application binary.
Future API releases must update the compatibility destination before removing
8151. Rollback must stop/disable this unit before restoring the original 8149
backend. No unrelated firewall rules are modified.
