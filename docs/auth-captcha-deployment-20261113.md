# 用户端及管理员人机验证修复 — 2026-11-13

## 问题与修复
已部署后端在陌生登录、注册/绑定邮箱发码和找回密码发码时要求 captcha_token，但当前前端没有挂载验证弹窗，也未处理 CAPTCHA_REQUIRED。恢复此前的 GoCaptcha 随机题型组件并正式纳入源码，在共享 HTTP 请求层识别人机验证要求。验证成功后仅重试原始请求一次；关闭、过期或导航离开会取消等待，不发送原始业务操作。使用 go-captcha-react 1.0.5，与生产后端题型保持兼容。

用户登录、管理员登录、注册发码、找回密码以及使用同一请求层的邮箱绑定发码同步生效。熟悉 IP/账号免验证规则仍由现有后端决定。未关闭人机验证、未降低后端限制，未发送真实邮件、未使用真实用户密码测试。

## 测试
- TypeScript/Vite 生产构建；Playwright 使用本机 Edge（Browser plugin not available）。
- 12 项验证码测试：用户/管理员完整交互、发码/找回密码、取消、题目过期刷新、服务不可用重试、取消后迟到的验证响应不重试、再次拒绝时不循环、熟悉账号不额外验证、六种题型显示。
- 320px 手机与桌面截图检查；同时运行 5 项积分操作回归。
- 全流程验证使用模拟验证码接口；线上检查真实验证码签发、未验证时拒绝登录/邮件操作，不自动解答真实验证码或操作真实账号。
