# 账户闲置政策取消 — v1.0.84

2026-11-08 用户明确取消“超过 30 天未使用即冻结账户”的政策。今后不得仅因未登录、未调用 API 或闲置超过 30 天冻结账户；账户安全审计、清理脚本和人工批量操作均应遵守。手动风控、退款等其他原因的冻结不受影响。

排查生产 v1.0.83 对应源码、主服务器 systemd timers 和 root cron，未发现持续运行的闲置自动冻结任务或配置开关。数据库中 7 个账户的原因精确为“超过30天未使用，按账户安全审计冻结（2026-11-01）”，与一次历史批量审计操作一致；不能据此宣称已检查所有外部调度系统。

通过生产管理接口逐一解冻这 7 个账户。数据库复核全部 is_active=true、frozen_reason 为空；另外 16 个冻结账户及其冻结原因完全未变。未修改余额、API Key 启用状态、密码或历史用量。

本次为政策与数据操作发布，版本 v1.0.84 指向本记录提交；运行程序仍为 v1.0.83，容器 midcode-cache-v1083-api-1。不需要构建、重启、代理切换或容器替换，因此没有本次需清理的旧容器。

操作前备份及复核结果仅存服务器 /root/fanapi-idle-policy-v1.0.84/before.json 和 result.json（0600），未提交凭据或用户资料。若确需回退，先复核账户之后的状态变更，再通过管理冻结接口逐个恢复备份中的原状态与原因；禁止覆盖后续人工处置。
